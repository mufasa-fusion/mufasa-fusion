# Security Policy

## Supported Versions

Security fixes are provided for the latest release of MuFASA only.

## Reporting a Vulnerability

If you discover a security vulnerability in MuFASA, please report it to us privately by email to
[mufasa-fusion@ait.ac.at](mailto:mufasa-fusion@ait.ac.at). Please do not report security vulnerabilities
through public GitHub issues, discussions or pull requests.

Please include as much of the following as you can:

- A description of the vulnerability and its possible impact
- The affected version
- Steps to reproduce it, ideally with a minimal code example

We will acknowledge your report, investigate it and keep you informed about the fix.
Please give us the chance to release a fix before you disclose the vulnerability publicly.
