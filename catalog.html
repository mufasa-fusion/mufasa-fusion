Processing Nodes#

  • → /

    Threshold

    Detect connected regions in a Map or BayesianMap.

  • →

    BayesianFusion

    Fuse two or more BayesianMaps by summing their log-odds.

  • →

    LogicalAnd

    Logical AND in log-odds space: element-wise minimum across inputs.

  • →

    LogicalOr

    Logical OR in log-odds space: element-wise maximum across inputs.

  • →

    MapFusion

    Base for fusion nodes that combine BayesianMaps element-wise.

  • →

    POM

    Probability Occupancy Map: Bayesian log-odds accumulation with exponential decay.

  • →

    DBSTREAMClusterer

    Base class for all pipeline nodes.

  • →

    KalmanTracker

    Base class for all pipeline nodes.

  • →

    ObservationFilter

    Pass-through node that drops Observations not matching the specified criteria.
