mufasa.graph_svg.draw.render(spec: mufasa.graph_svg.spec.GraphSpec, prefix: str | None = None, embed_assets: bool = True) → str#

Draw a graph description as an SVG string.

prefix makes ids unique when several graphs share a page. With embed_assets the SVG carries its own styles and hover script (e.g. for notebooks); without, the page must load graph.css and graph.js.
