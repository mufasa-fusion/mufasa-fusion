mufasa.graph_svg.spec.class_types(cls: type) → tuple[list[type], type | None]#

Data types declared by a node class.

Nodes that resolve their types later (at construction or wiring) declare their broadest valid types on the class, so a graph drawn from code shows what a class accepts and produces in general.

Parameters:

mufasa.graph_svg.spec.spec_from_code(source: str) → GraphSpec#

Describe the graph that example code builds, without running it.

Understands from module import NodeClass and assignments name = NodeClass(...) (a source) or name = NodeClass(...)(input, ...). Everything else, such as Graph(...) or graph.run(), is ignored.
