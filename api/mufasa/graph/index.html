Graph

The Fusion Graph, binding all nodes reachable from its inputs to outputs together.

Module Contents#

class mufasa.graph.Graph(inputs: list[mufasa.Node], outputs: list[mufasa.Node], *, crs: str | None = None, bbox: mufasa.BoundingBox | None = None, resolution: tuple[float, float] | None = None)#

The Fusion Graph, binding all nodes reachable from its inputs to outputs together.

It is responsible for type compatibility checking and orchestrates the execution of the fusion system via its run() method. It also distributes global configuration – crs, bounding box and map raster resolution – to every node.

plot_graph()#

Render the pipeline as an interactive Fusion Graph.

Ports on each node show the data types it accepts (top) and produces (bottom); hovering a node shows its full name and connections, hovering a port its concrete data type.

Returns a FusionGraphSVG, which displays itself in Jupyter notebooks and can be written to an .svg file with save().
