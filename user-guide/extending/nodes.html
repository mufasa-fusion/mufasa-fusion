Writing a Node#

Every step in a Fusion Graph is a Node. To add your own processing, data source or result sink, you subclass it and declare four things:

_input_types

The data types the node accepts. [] for input nodes.

_output_type

The data type the node produces. None for output nodes.

process()

What the node does with each piece of data it receives.

get_config()

The constructor arguments, so a graph using the node can be saved and loaded.

The examples on this page are small on purpose. Each one shows a different kind of node, and each one runs in a Fusion Graph with the sample data from the Tips and Tricks. They all share the same spatial setup:

from mufasa import Graph, BoundingBox

BBOX = BoundingBox(16.4255, 48.2675, 16.4295, 48.2710)  # WGS84: lon/lat
CRS = "EPSG:32633"  # UTM zone 33N, so the graph computes in metres
RESOLUTION = (5, 5)  # map cell size in metres

Processing Nodes#

Processing nodes hold the fusion logic. They have both input and output types, and sit between the input and output nodes of a Fusion Graph.

ConfidenceBoost#

The simplest kind of node receives one Observation at a time and passes one (or more) on to its successors. This one raises the confidence of every observation by a fixed factor:

from mufasa.node import Node
from mufasa.location import Observation


class ConfidenceBoost(Node):
    """Multiplies every observation's confidence by a fixed factor."""

    _input_types = [Observation]  # accepts Observation (and any subclass)
    _output_type = Observation  # emits Observation

    def __init__(self, factor: float = 1.2) -> None:
        super().__init__()
        self.factor = factor

    def process(self, obs: Observation) -> None:
        boosted = Observation(
            geometry=obs.geometry,
            timestamp=obs.timestamp,
            properties=obs.properties,
            confidence=min(obs.confidence * self.factor, 1.0),
        )
        for successor in self._successors:
            successor.process(boosted)

    def get_config(self) -> dict:
        return {"factor": self.factor}

Wire it between an input and an output node like any built-in node:

from mufasa.io.inputs import GeoJsonInput
from mufasa.io.outputs import LocationOutput

src = GeoJsonInput("sensor_b.geojson")
boost = ConfidenceBoost(factor=1.5)(src)
out = LocationOutput()(boost)

graph = Graph([src], [out], crs=CRS, bbox=BBOX, resolution=RESOLUTION)
graph.plot_graph()

graph.run()

[(round(before.confidence, 2), round(after.confidence, 2)) for before, after in zip(src.items(), out.result)]

[(0.94, 1.0), (0.55, 0.83), (0.79, 1.0)]

Each pair shows an observation’s confidence before and after the boost, capped at 1.0.

ComfortZone#

Nodes that process maps work differently. They aren’t handed the data. Instead, they are told that their predecessor has a new map, read it from self._predecessors[n].map, and call self._trigger_successors() once their own map is ready. They also create their map once, in configure(), when the graph tells every node its spatial setup.

This node ignores detections inside a zone you know is safe, for example where your own patrol vehicle is parked, so they don’t raise alarms. It takes the BayesianMap of a POM, converts it to a plain probability Map, and sets the probability inside the zone to zero. Which map cells the zone covers only depends on the spatial setup, so the node works that out once, in configure():

import numpy as np
import shapely
from pyproj import Transformer
from rasterio.features import geometry_mask

from mufasa.map import BayesianMap, Map


class ComfortZone(Node):
    """Ignores detections inside a zone you know is safe, such as your own base."""

    _input_types = [BayesianMap]
    _output_type = Map

    def __init__(self, zone_wkt: str) -> None:
        super().__init__()
        self.zone_wkt = zone_wkt  # polygon in WGS84 (lon/lat), as WKT so it can be saved and loaded
        self._map: Map | None = None
        self._inside: np.ndarray | None = None

    def configure(self, crs, bbox, resolution) -> None:
        self._map = Map.from_bounds(bbox, resolution, crs)
        # Project the zone into the graph's CRS and mark the map cells it covers, once
        to_crs = Transformer.from_crs("EPSG:4326", crs, always_xy=True).transform
        zone = shapely.transform(shapely.from_wkt(self.zone_wkt), to_crs, interleaved=False)
        self._inside = geometry_mask(
            [zone], out_shape=self._map.data.shape, transform=self._map.transform, invert=True,
        )

    def process(self) -> None:
        src = self._predecessors[0].map
        self._map.data[:] = src.probabilities
        self._map.data[self._inside] = 0.0  # nothing to worry about in here
        self._map.timestamp = src.timestamp
        self._trigger_successors()

    @property
    def map(self) -> Map:
        return self._map

    def get_config(self) -> dict:
        return {"zone_wkt": self.zone_wkt}

To make the detections visible on the map, we give them a spatial extent with the radius property (in metres): the first one, a large event right where our own patrol vehicle is parked, gets 30 m, the others 15 m.

import dataclasses

from mufasa.io.inputs import LocationInput
from mufasa.io.outputs import MapOutput
from mufasa.nodes.mapping import POM

zone = shapely.box(16.4260, 48.2680, 16.4273, 48.2689)  # where our own patrol vehicle is parked

detections = [
    dataclasses.replace(obs, properties={**obs.properties, "radius": 30 if i == 0 else 15})
    for i, obs in enumerate(GeoJsonInput("sensor_b.geojson").items())
]

src = LocationInput(detections)
pom = POM(decay_s=60)(src)
comfort = ComfortZone(zone.wkt)(pom)
out = MapOutput()(comfort)

graph = Graph([src], [out], crs=CRS, bbox=BBOX, resolution=RESOLUTION)
graph.plot_graph()

graph.run()

IO Nodes#

Input and output nodes form the boundary of a Fusion Graph. They connect it to files and external systems, and convert between their formats and MuFASA’s data models.

CsvInput#

Input nodes bring data into a Fusion Graph. They have no input types, and instead of process() they implement items(), which returns the data in temporal order. Coordinates are expected in WGS84; the graph projects them into its CRS for you.

This one reads detections from a CSV file like this:

timestamp,lon,lat,confidence
0,16.42664,48.26841,0.94
2,16.42684,48.26916,0.55
4,16.42712,48.26962,0.79

import csv

from shapely.geometry import Point

from mufasa.io.inputs import InputNode


class CsvInput(InputNode):
    """Reads detections from a CSV file with timestamp, lon, lat and confidence columns."""

    _output_type = Observation

    def __init__(self, path: str) -> None:
        super().__init__()
        self.path = path

    def items(self) -> list[Observation]:
        with open(self.path, newline="") as f:
            rows = list(csv.DictReader(f))
        return [
            Observation(
                geometry=Point(float(row["lon"]), float(row["lat"])),
                timestamp=float(row["timestamp"]),
                confidence=float(row["confidence"]),
            )
            for row in rows
        ]

    def get_config(self) -> dict:
        return {"path": self.path}

src = CsvInput(csv_path)
src.items()

AlarmPrinter#

Output nodes take the results of a Fusion Graph to the outside world: files, dashboards, alarm systems. They have no output type. Locations arrive in the graph’s CRS, so self._to_wgs84() converts them back to longitude and latitude.

This one raises an alarm for every observation above a confidence threshold:

from mufasa.io.outputs import OutputNode


class AlarmPrinter(OutputNode):
    """Prints an alarm for every observation above a confidence threshold."""

    _input_types = [Observation]

    def __init__(self, threshold: float = 0.8) -> None:
        super().__init__()
        self.threshold = threshold

    def process(self, obs: Observation) -> None:
        if obs.confidence >= self.threshold:
            obs = self._to_wgs84(obs)
            print(
                f"ALARM t={obs.timestamp:g}s at ({obs.geometry.x:.5f}, {obs.geometry.y:.5f}),"
                f" confidence {obs.confidence:.2f}"
            )

    def get_config(self) -> dict:
        return {"threshold": self.threshold}

Combined with the input node from above:

src = CsvInput(csv_path)
alarm = AlarmPrinter(threshold=0.75)(src)

graph = Graph([src], [alarm], crs=CRS, bbox=BBOX, resolution=RESOLUTION)
graph.plot_graph()

graph.run()

ALARM t=0s at (16.42664, 48.26841), confidence 0.94
ALARM t=4s at (16.42712, 48.26962), confidence 0.79

If an output node collects results and writes them at the end, for example to a file, override save(). The graph calls it once all inputs have been processed.

Saving and Loading#

Graph.to_config() stores a Fusion Graph as a JSON-serializable dict, using each node’s get_config(). To load it again with Graph.from_config(), register your node in the NODE_REGISTRY. The key must match the class name exactly:

from mufasa.registry import NODE_REGISTRY

NODE_REGISTRY["ConfidenceBoost"] = ConfidenceBoost

src = GeoJsonInput("sensor_b.geojson")
out = LocationOutput()(ConfidenceBoost(factor=1.5)(src))
config = Graph([src], [out], crs=CRS, bbox=BBOX, resolution=RESOLUTION).to_config()

restored = Graph.from_config(config)
restored.plot_graph()

See JSON Serialization for more on saving and loading Fusion Graphs.

Checklist#

Requirement

☐

_input_types declared ([] for input nodes)

☐

_output_type declared (None for output nodes)

☐

process() implemented (items() for input nodes)

☐

get_config() returns all constructor arguments as a JSON-serializable dict

☐

Registered in the NODE_REGISTRY, so graphs using the node can be saved and loaded

☐

configure() overridden if the node needs the spatial setup, for example to create a map

☐

reset() overridden if the node holds state that must be cleared between runs (see Graph.reset())
