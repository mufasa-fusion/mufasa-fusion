.. py:class:: GeoTiffInput(path: str)

   Bases: :py:obj:`mufasa.io.inputs.base.InputNode`


   Loads a single-band GeoTIFF file as a Map.

   The raster is returned in its native CRS. Reprojection and resampling to
   the pipeline's CRS, bounding box, and resolution is handled automatically
   by the InputNode base class.


   .. py:attribute:: path


   .. py:method:: items() -> list[mufasa.map.Map]

      Return items from this input in temporal order.

      File-based nodes return a sorted list. Streaming nodes return a
      blocking generator that yields as items arrive via ingest().



   .. py:method:: get_config() -> dict

      Return all constructor arguments as a plain JSON-serializable dict.

      Used by ``Graph.to_config()`` to serialise the pipeline. Every key
      must be a string; every value must be JSON-serializable.
