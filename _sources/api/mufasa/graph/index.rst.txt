.. py:class:: Graph(inputs: list[mufasa.Node], outputs: list[mufasa.Node], *, crs: str | None = None, bbox: mufasa.BoundingBox | None = None, resolution: tuple[float, float] | None = None)

   The Fusion Graph, binding all nodes reachable from its :attr:`inputs` to :attr:`outputs` together.

   It is responsible for type compatibility checking and orchestrates the execution of the fusion system
   via its :func:`run` method. It also distributes global configuration – :attr:`crs`,
   :attr:`bounding box <bbox>` and map raster :attr:`resolution` – to every node.

   .. py:method:: plot_graph()

      Render the pipeline as an interactive Fusion Graph.

      Ports on each node show the data types it accepts (top) and produces (bottom); hovering a node
      shows its full name and connections, hovering a port its concrete data type.

      Returns a :class:`~mufasa.graph_svg.FusionGraphSVG`, which displays itself in Jupyter notebooks
      and can be written to an .svg file with ``save()``.
